# X13 Gmail message-ID search — Phase 2 replay/result-digest Andon

The exact privacy-safe Phase-1 Gmail request arguments were read from the durable preflight and replayed once. The call returned three message IDs and a continuation token in 334 ms with no connector error, retry, fallback, content hydration, attachment fetch, or Gmail mutation.

The stored Phase-1 request descriptor recomputes exactly to its persisted SHA-256. However, that recomputation happened after the candidate call rather than before it, so this wake does not claim compliance with the stricter pre-call hash-verification gate later surfaced by the S15 replayability antibody.

More importantly, Phase 1 persisted an `ordered_result_digest_sha256` but did not persist the canonical byte representation used to derive it. Phase 2 therefore cannot honestly classify the old and new result digests as equal or different. This is a control-plane evidence-design Andon, not a Gmail connector failure. Raw Gmail message IDs and the page token are not persisted. Repeatability remains unknown.
