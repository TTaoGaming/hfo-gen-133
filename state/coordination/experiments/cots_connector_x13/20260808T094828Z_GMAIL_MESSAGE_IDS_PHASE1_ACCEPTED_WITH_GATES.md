Official Gmail `users.messages.list` documentation says native list results contain only message `id` and `threadId`, with additional details requiring `messages.get`; the native response may also contain `nextPageToken` and `resultSizeEstimate`. The wrapper is narrower in this observation: it exposed message IDs plus a page token, but not thread IDs or a result-size estimate. Native-method parity is therefore not assumed.

Those are provider-contract values only; the connector did not expose its effective Cloud project, native method mapping, provider request ID, or actual quota debit.
