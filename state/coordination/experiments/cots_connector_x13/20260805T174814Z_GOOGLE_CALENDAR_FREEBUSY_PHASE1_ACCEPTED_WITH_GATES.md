# X13 Google Calendar free/busy phase 1

One bounded read-only free/busy call queried the primary calendar over an explicit fifteen-minute interval and returned one busy window covering the full interval. It returned no event titles or details, no per-calendar error, no top-level error, and caused no mutation. The connector exposed 266 ms external call time.

The wrapper avoids OAuth transport, request-body, RFC3339, timezone, per-calendar result, and basic error-plumbing code, but its effective principal, scopes, ACL context, project, quota use, raw Google response, HTTP metadata, retry graph, and billing state remain unknown. Free/busy is less revealing than event retrieval but still exposes schedule occupancy and must be handled as sensitive data.
