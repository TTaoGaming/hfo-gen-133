## §3 · DISTRIBUTION STACK (5 tiers, cheapest to most expensive)

Every shipped unit automatically gets Tier 0 + Tier 1. Operator picks 2-5/week for Tier 2 promotion. Tier 3-5 only after product-market fit signal.

### TIER 0 · Free organic (all units, automatic)
- SEO-optimized landing page targeting 1-3 low-competition long-tail keywords per unit
- GitHub public repo with README + topics + description
- Sitemap.xml + robots.txt + Cloudflare Web Analytics
- Cross-linking between related units in factory footer

**Cost:** $0. **Time to signal:** 30-90 days. **Ceiling:** compounds if any hits SEO rank.

### TIER 1 · Free directories (all units, automatic ~2-3 days after ship)
Target list Sigrún is compiling. Known productive:
- BetaList, IndieHackers, SaaSHub, AlternativeTo, StackShare, TinyLaunch
- Product Hunt Ships (weekly submission, not full Product Hunt launch)
- Reddit r/SideProject weekly threads (not top-level post)
- HN "Ask HN" pattern threads
- 15-20 niche directories per vertical

**Cost:** $0 (or $50-200 one-time for a submission service). **Time to signal:** 7-30 days. **Ceiling:** slow trickle traffic.

### TIER 2 · Free community (operator-picked, requires voice)
Reserved for the 2-5 units/week that get concentrated push:
- Reddit AppAlchemy pattern to matched sub (1 sub / 1 post / 48hr reply presence)
- HN Show submission with technical title
- X thread from operator's account
- LinkedIn post from operator's profile
- Substack build-log post

**Cost:** $0. **Time to signal:** 3-14 days (fast fail signal). **Ceiling:** AppAlchemy proved $17k MRR from one Reddit post.

**Rate limit reality:** 1 substantive Reddit post per sub per 3-7 days; 1-2 HN Show per week per account. This IS the throughput ceiling — build > distribute.

### TIER 3 · Paid outreach (opt-in per campaign)
- Cold email via warmed Instantly domain ($40-100/mo tool + list building)
- LinkedIn cold outreach (Sales Navigator $79/mo + Expandi/Dripify $99-249/mo)
- Newsletter sponsorships targeting AI-dev audiences ($100-1,000 per placement)

**Cost:** $200-500/mo. **Time to signal:** 7-21 days. **Ceiling:** paid channels have knowable unit economics.

### TIER 4 · Paid partners (rev-share, agency, sponsorship)
- **Rev-share partner** — someone with existing audience takes 20-40% of first-year revenue for promoting your product. Zero upfront.
- **Agency partnership** — small AI/dev agencies (10-30 person shops) subcontract or resell. Usually 20-30% commission.
- **Creator sponsorship** — pay YouTubers/newsletter writers a flat fee ($200-2,000) for a review or mention.
- **Affiliate program** — 30% recurring commission on any referred paying customer, structured payout via LemonSqueezy/Rewardful.

**Cost:** rev-share is $0 upfront; sponsorships $200-2,000 each. **Time to signal:** 14-45 days. **Ceiling:** high if partner has right audience.

### TIER 5 · Paid ads (ONLY after PMF signal)
Do not spend paid ads until at least one unit has ≥10 organic paying customers.
- Google Ads on high-intent long-tail queries
- Reddit ads on niche subs
- Twitter/X ads on developer keywords

**Cost:** $200-2,000/mo. **Time to signal:** 3-14 days. **Rule:** kill any campaign with CAC > 3-month LTV within 14 days.

## §5 · FALSIFICATION DISCIPLINE (per unit, before ship)

Every unit ships with these fields populated BEFORE launch. No exceptions.

```yaml
unit_id: <slug>
build_at: <utc>
launch_at: <utc>
success_criterion: <observable, external, threshold>
falsifier: <what observation makes this DEAD>
decision_by: <utc — max 14 days post-launch>
current_state: {impressions: 0, signups: 0, paying: 0, revenue: 0}
kill_rules:
  - "0 impressions after 14 days" → SEO/directory copy is wrong, rewrite once then kill
  - "impressions >100 but 0 signups after 14 days" → landing page failure, A/B test once then kill
  - "signups >5 but 0 paying after 21 days" → pricing/value gap, iterate once then kill
  - "paying >0 but 0 retention beyond first month" → not recurring, convert to one-time or kill
```

**Portfolio-level rule:** if 5 consecutive units die at "0 impressions" — the factory template or directory-submission list is broken, not the units. Fix that before shipping unit 6.

## §10 · SUCCESS CRITERIA FOR THIS FRAMEWORK ITSELF

This framework is itself an experiment. Kill criteria:

- **Week 1:** if <10 units built OR <2 units actively launched (Tier 2) → build pipeline is broken, fix template
- **Week 2:** if 0 units have >100 impressions → distribution list is broken, expand
- **Week 4:** if <1 paying customer across portfolio → offer/positioning is wrong, iterate ICPs
- **Week 8:** if <$100 total revenue → framework is falsified, pivot to different archetype mix
- **Week 12:** if <$500/mo run-rate → framework is dead, redesign

Every week has a measurable checkpoint. No open-ended runway.
