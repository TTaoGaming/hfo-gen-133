# ADR-20260803-11 — Therapy vertical banned

- **Context:** Prior sessions considered mental-health / therapy adjacencies as micro-SaaS candidates. Operator banned this class outright.
- **Decision:** No therapy, mental-health matching, or clinical-adjacent unit may enter the target set. Sigrún has veto authority to reject any research surfacing this class.
- **Consequence:** Removes an entire adjacency without further debate.
- **Author:** operator (anchor)
- **Alternatives considered:** allow wellness-adjacent (rejected — same class in disguise).
