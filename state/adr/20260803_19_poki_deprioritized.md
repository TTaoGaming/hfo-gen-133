# ADR-20260803-19 — Poki portal deprioritized

- **Context:** D5 Gemini deep research explicitly said "AVOID Poki" (revenue-share terms, gatekeeper opacity, low SoloDev fit). Sigrún V3 recommended zero Poki submissions.
- **Decision:** Poki submissions marked LOW_PRIORITY in the operator approval queue. Approve selectively only if operator has specific reason.
- **Consequence:** CrazyGames + Kongregate remain the two primary HTML5 game portals for the sunk-inventory publish (ADR-09).
- **Author:** Gemini D5 + Sigrún V3; olrun (queue-annotation)
- **Alternatives considered:** ban Poki outright (rejected — operator explicitly asked for Poki inclusion in the source list, so we stage-but-flag rather than reject); Poki as primary (rejected — research is unambiguous).
