# ADR-20260803-02 — AI-dev tools promoted as target ICP

- **Context:** Six units built this session all target AI/agent developers as ICP. This is a deliberate reflection of operator's existing skill stack (Cloudflare + Stripe + Codex) and cold-outreach reachability (HN, r/LocalLLaMA, r/AI_Agents, LinkedIn AI-eng cohort).
- **Decision:** AI-dev tools becomes the primary ICP for FACTORY A (micro-SaaS). Any target that cannot be reached cold via AI-dev channels needs explicit Sigrún justification.
- **Consequence:** Distribution templates in `factory/distribution/` are tuned for HN Show + Reddit AI-dev subs + AI newsletter sponsorships, not general SaaS directories.
- **Author:** olrun (per Sigrún V11 SIX_LANES + operator skill-match filter in FRAMEWORK_GEN133_V1 §8)
- **Alternatives considered:** general SaaS ICP (rejected — distribution CAC unknown); creators/prosumers (deferred to FACTORY B desktop utilities).
