# P-OP-004 · ⭐ Weeks-long loops on tightly-scoped goals

> *"with a tightly scoped goal we are able to get lubes of hours and even weeks
> on end. I've so tests for weeks and we can do it but it's like very basic
> like heartbeats."*

**what_worked** — Loops have run for **hours to weeks** without human
intervention, when and only when the goal was tightly scoped.

**mechanism** — ⚠️ **Not established.** The operator reports the correlation
(tight scope ⇒ long life) and not the cause. My hypothesis is in [[S-OP-004]]:
tight scopes survive because they are *uncompletable*, so the agent never
reaches a state it can call done and exit. That is a hypothesis, and this row
must not be read as confirming it.

**evidence** —
- operator attestation of weeks-long heartbeat runs, 2026-08-01;
- **`SUBSTRATE_ROSTER.md` v0_2 CX-5: Codex desktop, 9h+ sustained goal loop,
  operator-confirmed 2026-07-30.** This is the strongest durability receipt in
  the estate and it is not a heartbeat — it was a *goal* loop.

**why this row matters more than its grade suggests** — Every roadmap
recommendation about durability is currently reasoning from the *absence* of
working loops. This row is the one positive example, and it has never been
characterized. **Characterizing the Codex 9h+ loop is cheaper than adopting any
harness and strictly precedes it** — adopting first would be [[S-OP-003]]
(reinventing/adopting without checking what already works) in its most expensive
form.

**bar_not_met** — ⚠️ does not meet the §2 splendor bar: no external effect, no
consumer. The operator's own qualifier is the honest summary — *"it's very basic
like heartbeats."* A loop that runs for weeks and produces nothing a stranger
can see is durability without production, which is precisely the gap this
generation exists to close.
