# P-OP-005 · Second-order cybernetics / extended cognition as the working frame

> *"the goal is that you can just leave a fair amount somewhere and the work
> will be like a Toyota production system where they work and they cycle
> through PDCA towards the goal themselves. it's a recursive adapting swarm.
> that's my second order cybernetics extended cognition system. I'm sure we can
> package and sell this some way… we're running it through a signal refinery
> using different techniques so that we can get better output than normal. we
> can apply that same principle to almost any industry."*

**what_worked** — A coherent, non-derivative design frame that has generated
real architecture rather than decorating it. Evidence that it is load-bearing
rather than a slogan:

- **Stigmergy** — chosen over direct messaging, and the choice is now backed by
  an observed failure of the alternative ([[S-OP-002]]).
- **Signal refinery** — not a metaphor. `signal_refinery.mjs` +
  `refinery_presets.mjs` exist on disk as the layer between raw landmarks and
  the application [D]. The same principle the operator wants to apply to LLM
  output is already implemented in his gesture stack. **The generalization he
  proposes has a working precedent in his own code.**
- **PDCA / Toyota** — produced the receipt discipline, the andon rules, and the
  no-DONE-without-receipt gate, all of which are in force.
- **Second-order framing** — the system observing and modifying its own
  observation rules is why the failure-class registry and the strife/splendor
  corpus exist at all, including this row.

**mechanism** — The frame's value is that it makes **the observer part of the
system under design.** Most agent architectures treat the human as an external
user; this one treats the operator's attention as the scarcest resource in the
loop and designs against that constraint. That is why the correct fitness
function is *income per operator-click*, not income — a conclusion that falls
out of the frame and does not fall out of a conventional one.

**evidence** — operator verbatim, 2026-08-01 · `signal_refinery.mjs` (3,224 B) +
`refinery_presets.mjs` (6,846 B) on disk [D] · the failure-class registry
(19 classes) and this corpus as artifacts of the second-order pass.

**bar_not_met** — ⚠️ **does not meet the §2 splendor bar, and the gap is the
important part.** No stranger has seen it; no consumer has accepted it. The
operator's own instinct — *"I'm sure we can package and sell this some way"* — is
the correct next step and it is **untested**, with one specific adversarial
caveat carried forward from prior canon: *demand for agent orchestration is not
demand for HFO*, and zero reference customers reads to a buyer as risk, not as
differentiation.

**The cheapest available test is in the roadmap as W3** — package ONE discipline
(the receipt gate) as a sellable skill, three hours, and let the market answer.
That is an information purchase, not an income lane, and it is priced as such.
