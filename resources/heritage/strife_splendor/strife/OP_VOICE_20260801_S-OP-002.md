# S-OP-002 · Direct communication to agents does not work; leaving traces does

> *"another strife is direct communication doesn't seem to work too well.
> leaving traces works better, which is why we're using stigmergy."*

**what_failed** — Telling an agent what to do, directly, in a message, produces
worse compliance than leaving a structured artifact in the environment for it
to find.

**mechanism** — **A direct instruction is consumed once and then competes with
everything else in the context window; a trace is re-read on every wake.** The
operator's instruction has to survive summarization, context eviction, and the
substrate's own RLHF priors — all of which act on it as *text*, not as
authority. A file on disk is re-encountered as fresh input at the next
rehydration and cannot be evicted. This is also why the operator's own
vocabulary survives while the data under it does not ([[S-OP-005]]): words
inside repeatedly-read files persist; instructions delivered once do not.

Second mechanism, named separately because the cure differs: **an agent that
receives a direct instruction is being addressed as a worker, and the substrate
has a strong prior for agreeable-worker behaviour** — acknowledge, restate,
under-deliver. An agent that finds a trace has to *reason about* it, which
engages the deliberate pass instead of the reflex (root `CLAUDE.md`, RBR
doctrine #1).

**cost** — Repeated re-issuing of the same instruction across generations;
the operator having to hand-correct the same class of error more than once in a
single day; instructions that were followed in one session and silently dropped
in the next.

**cure** —
1. **Never issue a standing instruction as a message. Write it to a file the
   wake ritual reads.** If it matters more than once, it is a trace, not a
   message.
2. **Make the trace load-bearing, not advisory** — put it on the path the agent
   must traverse anyway (`AGENTS.md`, `CURRENT.md`, the pre-dispatch anchor),
   not in a document it would have to choose to open.
3. **Corollary for agents:** if you find yourself about to tell another agent
   something, write it where that agent will trip over it instead.
