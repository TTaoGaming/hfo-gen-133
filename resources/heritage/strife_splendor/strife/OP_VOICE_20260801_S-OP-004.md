# S-OP-004 · Agents self-stop — even on loops, even with tight scope

> *"another major strife is self-stopping completely which is really weird, but
> even if we put them on loops right like they just sort of stop and they just
> don't do anything further so it's really hard to loop them. whereas you know
> with a tightly scoped goal we are able to get lubes of hours and even weeks
> on end. I've so tests for weeks and we can do it but it's like very basic
> like heartbeats. what I want is a loop of productive factory applications and
> I think we're close but we're not there yet."*

**what_failed** — Agents placed on loops stop producing. The failure has a
sharp shape the operator identified precisely: **loop duration and loop
productivity trade off against each other.** Tightly-scoped goals run for weeks
but only produce heartbeats. Productive goals stop within a session. Nothing has
yet been both durable and productive.

**mechanism** — ⚠️ **This field is Sigrún's inference, not the operator's
words.** He reported the phenomenon and explicitly called it "really weird" —
i.e. he does not have the mechanism, and I will not put one in his mouth.

My proposed mechanism, offered as a hypothesis to be falsified rather than as a
record: **a loop with a completable goal terminates when the agent believes the
goal is met, and an LLM's belief that a goal is met is cheap to produce.** The
heartbeat loops survive precisely because their goal is *uncompletable*
(emit a timestamp, forever) — there is no state in which the agent can conclude
"done." Productive goals are completable, so the reflex reaches "done" long
before the work is done, and the loop exits on a false green. That would make
self-stopping the same defect as `L-LYGIS-SÁÐ` (DONE without receipt) expressed
in the time dimension rather than the claim dimension.

**If that is right, the cure is not a better harness — it is a loop whose exit
condition is an external receipt rather than an agent's judgement.** That is a
testable difference and §5/M2 of the roadmap is designed to test it.

**cost** — 78 of 81 scheduled tasks disabled. The 3 still enabled are
heartbeats. Zero productive autonomous loops in the estate; the one long-running
counterexample (Codex, 9h+) has not been characterized, so its durability
mechanism is unknown and therefore not reproducible.

**cure** —
1. **Before adopting any harness, characterize the ONE loop that already
   works.** The Codex 9h+ loop is the only positive data point in the estate;
   adopting LangGraph before understanding it would be [[S-OP-003]] in action.
2. **Make loop exit require an external receipt** — a URL that returns 200, a
   file another process wrote, a reply. Never the agent's own assessment.
3. **Instrument the stop.** No current record says *why* any loop stopped. Until
   a stop is observed rather than inferred, every cure here is a guess.

**evidence** — operator verbatim, 2026-08-01 · 78/81 disabled-task figure from
gen-130 capacity audit, carried in `SIGRUN_SPATIAL_GESTURE_SWARM_INCOME_CASE_STUDIES_20260801.md`
