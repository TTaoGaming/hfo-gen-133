# S-OP-003 · Reinventing instead of adopting

> *"a major strife pattern is reinventing instead of adopting so constantly
> like reinventing old things over and over instead of just adopting what
> worked before or web research and adopting exemplars."*

**what_failed** — The system rebuilds machinery it already has, and rebuilds
machinery the world already sells, instead of adopting either.

**mechanism** — **Building is the cheapest action available to an LLM agent and
adopting is the most expensive.** Writing a novel loop harness costs one
generation pass; finding the prior generation's working one costs a search
across 133 forges with no index, and adopting an external exemplar costs a web
search plus reading someone else's abstractions. The action with the lowest
immediate token cost is chosen, every time, and it is the wrong one. The
substrate's reflex prefers generation over retrieval because generation is what
it is (root `CLAUDE.md`, RBR — reflex beats reasoning).

Compounding it: **a rebuilt thing looks like progress and a reused thing looks
like nothing happened.** There is no artifact to show for adoption, so the
incentive gradient points at reinvention even when the operator has explicitly
asked for adoption.

**cost** — 133 generations of bespoke loop machinery, and exactly **one**
substrate that has demonstrably looped for hours (Codex, 9h+, operator-confirmed
2026-07-30). The estate contains many harnesses and one working loop. Directly
observed this session: a roster reconciliation was nearly re-derived from zero
by a lane that did not know an identical reconciliation already existed at
`chains/SIGRUN_P4.jsonl` line 29.

**cure** —
1. **Before building anything, the mandatory question is "who already has
   this — inside the estate, or outside it?"** and the answer must cite a path
   or a URL, including when the answer is "nobody."
2. **Prefer a named external exemplar over an internal one, and an internal one
   over new work.** The operator's own doctrine already says this — *take what
   is given*, best-tool-for-the-job — and it is being violated by the default
   action, not by disagreement.
3. **Make adoption produce an artifact** (an adoption ADR naming what was taken
   and from where) so that reuse is as visible as invention.

**evidence** — operator verbatim, 2026-08-01 · corroborated by
`OLRUN_ROSTER_AND_CLASS_RECONCILIATION_20260801.md` §0 and §3 ("If a future wake
finds itself about to repeat this reconciliation from zero again, that is itself
a CAPACITY_AMNESIA-shaped event").
