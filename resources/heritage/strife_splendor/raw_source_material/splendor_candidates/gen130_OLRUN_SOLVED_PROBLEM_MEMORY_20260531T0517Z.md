## Purpose

This is the compact "remember this before building" map for the Gen130 one-button arcade and universal keybar work. It consolidates solved problems, failure modes, and standard work from the heritage reliquary, Olrun/Hrist/Sigrun inboxes, and current launch receipts.

The rule is simple: heritage is evidence, not authority. A capability becomes usable only when the current generation has file hashes, imports, tests, red-team receipts, and a liveness or golden witness appropriate to its claim.

## Current Operational Truth

- The first launch wedge is browser-local: one hand, one index cursor, one Space hitbox, one-button arcade bridge.
- Automated smoke and the full Olrun capacity guard are green enough for a private browser smoke, but not for production: golden MP4 to T-Rex and launch readiness are green; manual webcam T-Rex witness is still pending.
- CPU MediaPipe worker is the default detector path for the wedge. GPU remains selectable but perf-red until receipts prove otherwise.
- `hfo_tiles` is the certified reuse surface. New roots should consume certified exports instead of copying or re-solving keybar/bridge behavior.
- Gesture sentence is now a candidate path for `ready -> commit -> release`, but it has no trusted output authority until manual webcam and runtime adapter certification are done.
- Browser pointer runtime is candidate-green as a same-origin synthetic browser-event adapter, but still not a trusted export or OS input path.
- v0.21 remains a quarantine lesson: a root can be green while bypassing the real input spine. This is why liveness, swap-sensitivity, and transit receipts matter.

## Standard Work For The Current Launch

1. Use `hfo_tiles` for certified keybar/game target/bridge behavior.
2. Run `npm.cmd run guard:capacity` in the Olrun one-button lane before any green claim.
3. If testing launch readiness, run `npm.cmd run launch:readiness` and read the generated report.
4. Serve and manually witness only after automated smoke is green.
5. Manual witness target: 20 intentional webcam hits, 0 random outside hits, 0 stuck keys, provider/FPS recorded.
6. Promote nothing to production or Gold without Semgrep/OPA/Nx/Stryker-class real tools, restore drill, device/browser matrix, and manual witness.
