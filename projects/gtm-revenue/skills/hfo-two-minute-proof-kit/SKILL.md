# Two-Minute Proof Kit

## Trigger
Use when a researched target has a public signal plus one plausible expensive pain and needs a small useful artifact before outreach/application.

## Procedure
1. Bind the exact target-research card and source URLs.
2. Choose one problem only.
3. Choose one artifact only: scorecard, checklist, policy starter, routing table, ROI worksheet, FMEA, trace schema, authority matrix, 30/60/90 checklist, architecture, prompt pack, defensive test pack, or business-case template.
4. Make it useful without a sales conversation.
5. Put `WHY_THIS_MAY_MATTER` and `HOW_TO_USE_IN_2_MINUTES` at the top.
6. Separate public facts, assumptions, and hypotheses.
7. Use operator capabilities only at evidence ceiling: held-out evals/release gates, multi-quorum verification, OPA/Rego, model routing/tiering, observability, bounded workflow automation.
8. Add one falsifier and one optional small follow-up question.
9. Route to a non-author verifier before external use.

## Acceptance
- one screen / one page where practical
- zero invented customer failures or savings
- no macros/executables
- no confidential data
- source pointers present
- useful even when recipient never hires/buys

## Stop rules
No send, application submission, deployment, exploit, credential use, or self-verification.

## Fitness
Recipient engages with artifact, corrects the hypothesis, agrees to discovery, interviews operator, requests deeper proof, or refers onward.
