# Freelance Contract Sender Starter

A proposal-to-milestone-cash workflow for freelance studios and consultants: scope brief, proposal PDF, provider-neutral e-sign handoff, milestone ledger, and billing reminders.

- Base: Activepieces core at `8d29bbe6fdd572b15398adc67dff74b2e30d3a3d`
- License: MIT for core content; enterprise paths are excluded
- Buyer signal: freelancers rebuild scopes and contracts from prior documents, then track signatures, milestones, and invoices across unrelated tools
- Starter state: no legal document send, signature provider, client data, charge, message, or production deployment

Documenso was considered for e-sign but is `AGPL_SKIPPED`; this starter keeps a provider-neutral signature boundary. The clone is sparse. Run `git sparse-checkout disable` to materialize the complete upstream tree.
