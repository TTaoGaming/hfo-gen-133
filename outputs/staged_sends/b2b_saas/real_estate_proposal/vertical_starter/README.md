# Real-Estate Proposal Starter

A listing-intake-to-proposal workflow for independent agents and small broker teams: property brief, market-analysis packet, proposal PDF, approval, and onboarding invoice task.

- Base: Activepieces core at `8d29bbe6fdd572b15398adc67dff74b2e30d3a3d`
- License: MIT for core content; enterprise paths are excluded
- Buyer signal: agents repeatedly assemble listing presentations from form answers, MLS exports, comps, and branded documents under deadline
- Starter state: configuration only; no MLS credentials, listing data, signatures, live payments, sends, or production deployment

The clone is sparse. Run `git sparse-checkout disable` to materialize the complete upstream tree.
