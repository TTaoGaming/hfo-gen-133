# Coach Booking Starter

An intake-to-renewal workflow for independent coaches and small practices: goals, package proposal, approved billing handoff, session schedule, notes task, and renewal review.

- Base: Cal.com at `038381aeca6261635357957d66b8ba85cdb29737`
- License: MIT (current root LICENSE)
- Buyer signal: coaches duplicate goals, package selection, invoices, calendar events, and session notes across forms and personal tools
- Starter state: no public booking endpoint, client records, charges, messages, or production deployment

The clone is sparse. Run `git sparse-checkout disable` to materialize the complete upstream tree.
