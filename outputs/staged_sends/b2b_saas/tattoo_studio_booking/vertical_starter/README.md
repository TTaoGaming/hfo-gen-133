# Tattoo Studio Booking Starter

A consultation-to-aftercare workflow for independent tattoo studios: consult request, design brief, approved deposit handoff, artist scheduling, and aftercare follow-up.

- Base: Cal.com at `038381aeca6261635357957d66b8ba85cdb29737`
- License: MIT (current root LICENSE)
- Buyer signal: studios coordinate artist fit, references, deposits, and reschedules across DMs, forms, and personal calendars
- Starter state: no public booking endpoint, customer data, deposit charge, messages, or production deployment

The clone is sparse. Run `git sparse-checkout disable` to materialize the complete upstream tree.
