# Auto Detailer Intake Starter

A photo-intake-to-follow-up workflow for mobile and shop detailers: vehicle brief, pricing review, deposit handoff, scheduling, and review/rebook follow-up.

- Base: Activepieces core at `8d29bbe6fdd572b15398adc67dff74b2e30d3a3d`
- License: MIT for core content; enterprise paths are excluded
- Buyer signal: detailers quote from inconsistent photo threads, then copy appointments and deposits between phone, calendar, and payment apps
- Starter state: no photo upload store, customer data, charges, messages, or production deployment

The clone is sparse. Run `git sparse-checkout disable` to materialize the complete upstream tree.
