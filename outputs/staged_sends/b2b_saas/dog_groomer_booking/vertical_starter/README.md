# Dog Groomer Booking Starter

A request-to-rebook workflow for independent groomers: pet and allergy intake, quote/waiver review, deposit handoff, schedule, and aftercare/rebook task.

- Base: Cal.com at `038381aeca6261635357957d66b8ba85cdb29737`
- License: MIT (current root LICENSE)
- Buyer signal: groomers screen pet size, coat, behavior, vaccinations, and allergies in messages before manually finding a viable slot
- Starter state: no public booking endpoint, pet/customer records, charges, messages, or production deployment

The clone is sparse. Run `git sparse-checkout disable` to materialize the complete upstream tree.
